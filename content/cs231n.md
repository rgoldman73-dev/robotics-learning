## 2
read: CS231N notes: Linear classification; PoRA Chapter 9
Q: What is a linear classifier? => Scores s = W x + b for each class, predicting the highest score.
Q: What does a softmax cross-entropy loss do? => Turns scores into probabilities and penalizes low probability on the true class.
Q: Why call linear classification a "template matching" view? => Each row of W acts as a template compared by dot product with the image.
X: Compute softmax for scores [2,1,0] and the loss if class 0 is correct.
R: Linear classifiers + a loss function define the learning problem that neural networks generalize.
## 3
read: CS231N notes: Optimization; Neural nets part 3
Q: What does regularization do? => Penalizes model complexity (e.g. L2) to improve generalization.
Q: Describe gradient descent. => Repeatedly move parameters opposite to the gradient of the loss.
Q: Why use SGD with mini-batches? => Cheap noisy gradient estimates make training large datasets feasible.
Q: What do momentum/Adam add? => Smoothing of gradient direction and per-parameter adaptive step sizes.
X: Minimize f(w)=(w-3)^2 with gradient descent for learning rates 0.1, 1.0, 1.1 and compare.
R: Training = loss + regularizer + an optimizer; learning rate is the key knob.
## 4
read: CS231N notes: Backpropagation; PoRA Chapter 9
Q: What is backpropagation? => Applying the chain rule backward through a computation graph to get the gradient of the loss with respect to all parameters.
Q: Why do neural networks need non-linear activations? => Without them, stacked layers collapse to a single linear map.
Q: In a computation graph, what does an upstream gradient times a local gradient give? => The gradient flowing to the node's input.
X: Hand-backprop through f = (x*y)+z with x=2,y=3,z=1.
R: Backprop = efficient chain rule; autodiff frameworks do it for you.
## 5
read: CS231N notes: Convolutional networks; PoRA Chapter 9
Q: What does a convolutional layer exploit? => Local connectivity and weight sharing, so features are detected anywhere in the image with few parameters.
Q: What do pooling and stride do? => Reduce spatial resolution and compute while adding some translation invariance.
Q: Output size of a convolution with input N, kernel K, padding P, stride S? => floor((N - K + 2P)/S) + 1.
X: Calculate the output shape for a 32x32 image, 5x5 kernel, stride 1, padding 0.
R: CNNs use convolution, nonlinearity and pooling to build hierarchical features from pixels.
## 6
read: CS231N notes: Architectures; PoRA Chapter 9
Q: What problem do residual connections solve? => They ease optimization of very deep nets by letting layers learn residuals (identity shortcut).
Q: What does batch/layer normalization do? => Stabilizes activations and speeds up training.
Q: Why did networks get deeper over time (AlexNet -> VGG -> ResNet)? => More depth increases representational power if training can be stabilized.
X: Count parameters of a conv layer with 64 filters of 3x3 over 3 input channels.
R: Architecture design (depth, residuals, normalization) drives accuracy and trainability.
## 8
read: CS231N notes (attention); PoRA Chapter 9
Q: What is self-attention? => Each token computes weights over all tokens (via query-key dot products) and takes a weighted sum of values.
Q: Why did transformers take over vision? => They scale well with data and compute and model long-range relations; Vision Transformers apply them to image patches.
Q: What do queries, keys and values mean? => Queries ask, keys are what tokens offer to match, values carry the information that is mixed.
X: Explain attention in one paragraph with no equations (Month 3 milestone).
R: Attention computes data-dependent weighted mixtures; transformers use it to process sequences or patch tokens.
## 9
read: CS231N notes; PoRA Chapter 10 Object Detection and Recognition
Q: Detection vs segmentation? => Detection outputs boxes + classes; segmentation labels each pixel (semantic or instance).
Q: What is IoU? => Intersection over union of two regions, used to match/score detections.
Q: Why does a robot need detection/segmentation rather than classification? => It needs to know where objects are, not only what is in the image.
X: Compute IoU for boxes (0,0,2,2) and (1,1,3,3).
R: Detection and segmentation localize objects; essential to connect perception to manipulation.
